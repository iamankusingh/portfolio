## Experience Principles

The following principles should guide product decisions.

### 1. The Website Itself Is a Project

The portfolio's interaction, engineering, visual quality, loading, accessibility, and responsiveness are evidence of craft.

### 2. Use 3D Selectively

Use a hybrid 3D + DOM approach: immersive scenes frame key moments while semantic HTML carries substantive content. Scene responsibilities belong in [THREE_D.md](THREE_D.md).

### 3. Content Comes Before Effects

Effects must support content and never hide essential information behind interaction.

### 4. Motion Must Have a Purpose

Motion should explain relationships or changes. [MOTION.md](MOTION.md) defines the motion system.

### 5. Premium Does Not Mean Busy

Balance spectacle with calm editorial layouts, whitespace, and restrained interactions.

### 6. Mobile Is a First-Class Experience

Maintain the same visual identity, content, and complete experience across mobile and desktop modern browsers. Adapt layout, input, and rendering cost to each device without creating a diminished mobile design.

### 7. Accessibility Is Part of the Design

Support keyboard navigation, readable contrast, reduced motion, semantic HTML, and non-WebGL access.

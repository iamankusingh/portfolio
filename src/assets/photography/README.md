# Photography assets

Add optimized AVIF, WebP, JPEG, or PNG photographs here. In `src/data/photographs.ts`, set each entry's exact `image` filename, accurate `alt`, and `isPlaceholder: false`. Optional `objectPosition` controls the crop (for example, `"50% 35%"`). Use unique IDs.

The homepage uses every entry in order; the first opens at the center and the first eleven form the opening collage. Further entries extend the scrolling rows automatically. Add or remove entries to change the collection. Missing filenames use the approved `src/assets/anku.avif` portrait. Placeholder status remains in data and alt text; the visible preview caption is removed by user direction. No photographs from the inspiration screenshot are included.

Keep original full-resolution files outside the shipped source; use appropriately sized web exports and retain ownership/license records for supplied images.

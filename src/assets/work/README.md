# Project images

Place still images here, then set each record's `image` in `src/data/projects.ts` to the exact filename including its extension, for example `image: "my-project.webp"`. The component resolves that filename through Vite; there is no extension list or missing-file lookup.

All entries currently use `placeholder.svg` with Coming soon copy. Replace the filename, alt text, and copy when the work is ready. The named file must exist. Landscape images around 1600px wide are a useful starting point; images are contained without cropping. No video is used.
